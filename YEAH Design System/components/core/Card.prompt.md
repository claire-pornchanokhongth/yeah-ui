The workhorse container. Square corners always — the brand's rounding lives in pills and circles, never in boxes.

```jsx
<Card tone="yellow" shadow="block" interactive>
  <h3>Pitch Night #04</h3>
</Card>
```

Tones alternate across a grid (white / yellow / pink / black) to build the poster rhythm. Use `shadow="none"` when cards sit flush inside another bordered container, otherwise the doubled rules read as noise.
