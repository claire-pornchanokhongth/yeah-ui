Single icon glyph. Lucide SVG fetched from the CDN and inlined (so it survives screenshot/PDF/PPTX re-renders), 2px stroke — chosen to match the monoline construction of the YEAH mark. Flagged substitution: no icon set was supplied in the CI.

```jsx
<Icon name="calendar" size={24} />
```

Inherits `currentColor`, so it takes the colour of surrounding text automatically. Use 16px inside `sm` controls, 20px default, 24px in headers, 32px+ only as a decorative feature. Do not mix with emoji or other icon families.
