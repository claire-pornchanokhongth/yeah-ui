Round icon-only button. Use when the action is obvious from the glyph alone — close, next, share, bookmark.

```jsx
<IconButton icon="arrow-right" variant="primary" label="Next" />
```

Always circular (never a rounded square). Carries a 2px shadow at rest rather than 4px, so a row of them doesn't read as heavier than a single Button. `ghost` drops border and shadow for dense toolbars.
