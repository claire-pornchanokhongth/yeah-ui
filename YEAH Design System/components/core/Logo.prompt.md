Renders the supplied YEAH logo bitmap. Set `basePath` to reach `assets/` from wherever the page lives.

```jsx
<Logo variant="knockout" height={40} basePath="../../assets/" />
```

Clear space: at least the height of the mark's stem on all sides. Minimum size 24px for `mark`, 32px for the lockup (below that the tagline is illegible — use `mark`). Use `knockout` on black; use `lockup` on white and on yellow. Do not place the full-colour lockup on pink.
